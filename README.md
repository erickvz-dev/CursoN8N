# Curso N8N - Diplomado IA & Automatización

Bienvenido a mi repositorio personal del **Diplomado en IA & Automatización**. Este espacio contiene todos los ejercicios, prácticas y proyectos (sprints) desarrollados a lo largo del curso utilizando herramientas de automatización como **n8n**, **OpenAI**, **Telegram**, **Canva**, entre otras.

## 📂 Estructura del Repositorio

- **`diplomado-ia-automatizacion/`**: Contiene el material oficial del diplomado, instrucciones, reglas de agentes (AGENTS.md) y las configuraciones base para trabajar con Antigravity y diferentes herramientas (skills).
- **Sprints Personales (`Sprint 5/`, etc.)**: Contienen mis ejercicios prácticos, flujos JSON de n8n y apuntes (como el Cerebro Maestro o Reportes en Tiempo Real) desarrollados como parte de los entregables del curso.

## 🚀 Sobre el Diplomado

El curso se divide en diferentes automatizaciones (MVPs) diseñadas para implementar flujos de trabajo inteligentes en distintas áreas:
1. **Asistente Personal por Voz**
2. **Producción Visual Automatizada**
3. **Marketing y Orquestación**
4. **Recursos Humanos**
5. **Operaciones y Control de Gastos**
6. **Finanzas**
7. **Ventas y Capstone final**

Para más detalles sobre la configuración del entorno, integraciones MCP, y comandos de inicialización, por favor, consulta el [README Oficial del Diplomado](./diplomado-ia-automatizacion/README.md).
